# Contributing Guide

## Getting Started

1. Fork the repository on GitHub.
2. Clone your fork locally:
   ```
   git clone https://github.com/your-username/project.git
   cd project
   ```
3. Create a feature branch from `main`:
   ```
   git checkout -b feature/your-feature-name
   ```

## Making Changes

- Follow the existing code style (PEP 8 for Python).
- Write tests for any new functionality.
- Keep commits small and focused. Each commit should represent one logical change.

## Opening a Pull Request

1. Push your branch to your fork:
   ```
   git push origin feature/your-feature-name
   ```
2. Open a pull request on GitHub against the `main` branch of the upstream repository.
3. Fill in the pull request template — include a summary, motivation, and testing steps.
4. Request a review from at least one maintainer.

## Code Review

- All pull requests require at least one approving review before merge.
- Address review comments by pushing new commits to the same branch.
- Do not force-push to a branch that already has an open pull request.

## Reporting Issues

Open a GitHub issue with a clear title, description of the problem, steps to reproduce,
and the expected vs. actual behavior.
